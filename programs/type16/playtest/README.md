# TYPE/16 Playtest (preview only)

This folder is an isolated test built from Gesture Lab v0.11.1. The original `../gesture-lab.html` remains unchanged.

- First 12 questions are balanced across IE/SN/FT/JP, followed by an exploratory result checkpoint.
- The user can continue through the remaining 20 questions, adaptively ordered with the existing deterministic engineering heuristic, or revisit skipped questions.
- The genuine 32 OEJTS 1.2 items, scoring key and bilingual TYPE/16 interpretation engine are copied as a **self-contained snapshot** from `feature/type16-foundation` under `js/`; no CDN or third-party backend.
- The eight **pre-existing** motifs in Gesture Lab are reused as temporary illustrations. All rejected new SVG artwork has been excluded.
- The lab's swipes, controls, tutorial, animations and card reverse remain the visual foundation.
- Distinct localStorage key: `type16.playtest.v1`. No tracking, no upload and no data sharing.
- This is an educational prototype, not an official MBTI instrument or a clinically validated test. The 12-question reading is descriptive, not a calibrated psychological conclusion.
